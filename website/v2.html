🚀 V2 Vision

Die Zukunft von Secretariat

V1 ist da – dein lokaler, sicherer Vault. V2 macht Secretariat zur plattformunabhängigen Secret-Plattform für Teams. Wir wollen wissen: Was brauchst du?

Roadmap

Was kommt als Nächstes?

Von lokal zu vernetzt – Schritt für Schritt.

🔐
V1 · Jetzt live
Lokaler Vault + CLI + SDK
AES-256-GCM, SQLCipher, macOS Keychain, Python SDK, TCP Multi-Device, LaunchAgent. Läuft komplett lokal.
☁️
V2 · In Entwicklung
Cloud-Sync & Backup
Verschlüsselter Sync zwischen mehreren Maschinen. Optionales Cloud-Backup (Ende-zu-Ende-verschlüsselt, wir sehen nichts).
👥
V2 · Priorisiert
Team-Vaults & Sharing
Geteilte Secrets im Team. Granulare Zugriffsrechte, Audit-Log, Rollback-fähig. Ideal für DevOps-Teams.
🖥️
V2 · Erweiterung
Web UI & IDE Integration
Browser-basierte Vault-Verwaltung. VS Code Extension, JetBrains Plugin. Secrets direkt aus der IDE abrufen.
🔑
V2 · Advanced
Multi-Platform & Provider
Windows & Linux Support. Integration mit 1Password, Bitwarden, HashiCorp Vault als Sync-Provider.
🤫
V2 · Secret
Noch nicht verraten
Ein Ass im Ärmel. Sag uns, was du dir wünschst – dein Feedback beeinflusst die Roadmap.
Vergleich

V1 vs. V2 – was sich ändert

V1 ist dein persönlicher Tresor. V2 wird die Plattform für dein gesamtes Team.

V1 · Solo
✅ Lokaler Vault (SQLCipher)
✅ CLI + Daemon
✅ Python SDK
✅ TCP Multi-Device
✅ macOS Keychain
⚠️ macOS only
❌ Cloud-Sync
❌ Team-Sharing
❌ Web UI
❌ IDE Integration
❌ Audit-Log
❌ Provider-Bridge
V2 · Team & Cloud
✅ Lokaler Vault (SQLCipher)
✅ CLI + Daemon
✅ Python SDK
✅ TCP Multi-Device
✅ macOS Keychain
✅ Windows & Linux
✅ Cloud-Sync (E2E-verschlüsselt)
✅ Team-Vaults & Sharing
✅ Web UI
✅ VS Code & JetBrains
✅ Audit-Log & Rollback
✅ Provider-Bridge (1PW, Bitwarden, Vault)
