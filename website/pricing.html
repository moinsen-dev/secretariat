Häufige Fragen

💡 Kann ich Secretariat komplett kostenlos nutzen?
Ja. Der lokale Vault, CLI, SDKs, TCP Multi-Device — alles kostenlos, für immer. Selbst die Team-Features sind kostenlos, wenn du sie self-hosted betreibst. Du zahlst nur für Cloud-Dienste (Sync, Web UI).
🔒 Ist der Quellcode einsehbar?
Ja — BSL-Lizenz. Du kannst den Code auf GitHub einsehen, auditieren, forken. Einzige Einschränkung: Du darfst keinen Konkurrenz-Cloud-Dienst daraus bauen. Self-hosting ist immer erlaubt.
☁️ Wo werden meine Secrets bei Cloud-Sync gespeichert?
Ende-zu-Ende-verschlüsselt. Der Server sieht nur verschlüsselte Blobs. Der Entschlüsselungs-Key bleibt auf deinen Geräten — wir können deine Secrets nicht lesen. Mehr im Datenschutz.
🔄 Wann wird der Code Open Source?
Am 1. Januar 2029 wird die BSL-Lizenz automatisch zu Apache 2.0. Dann ist Secretariat vollständig Open Source — für immer. Bis dahin: Code ist öffentlich, Lizenz schützt das Geschäftsmodell.
