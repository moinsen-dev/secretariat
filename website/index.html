🔐 Secret Management für Developer

Secretariat ist ein lokaler, hochsicherer Secret-Manager für Developer. API-Keys, Tokens, Zertifikate – verschlüsselt auf deiner Maschine, erreichbar via CLI, Python SDK oder TCP-Netzwerk.

Features — V1

Was Secretariat heute kann

Ein schlanker, schneller Secret-Manager. Keine Cloud-Abhängigkeit. Keine Datenbank-Setups. Einfach secret set und los.

⚡
CLI-First
secret set/openvpn/key, secret get, secret list — alles aus dem Terminal. Autocomplete inklusive.
🛡️
AES-256-GCM Vault
SQLCipher-basierter Vault. Master-Key in der macOS Keychain (mit 5s Timeout für Headless-Betrieb).
🐍
Python SDK
from secretariat import Vault — deine Secrets direkt aus Python-Scripts, ohne Subprozesse.
🔗
TCP Multi-Device
Vault via TCP von anderen Rechnern im Netzwerk abfragen. Auth-Token-geschützt, TLS-optional.
🦀
Rust-Kern
Geschrieben in Rust — schnell, speichersicher, kein GC-Pausen. Daemon + CLI in einer Binary.
🔁
LaunchAgent Autostart
Daemon startet mit dem Mac. Via LaunchAgent, kein manuelles Starten nötig. Immer bereit.
Quick Start

In 3 Schritten zum eigenen Vault

Rust installiert? Dann los:

1
Installieren
Binary aus GitHub Release laden oder cargo build --release
2
Vault initialisieren
secret init — legt verschlüsselten Vault an. Key sichert macOS Keychain.
3
Secrets verwalten
secret set /github/token sk-... — fertig. secret get /github/token zum Lesen.
$ secret set /deepseek/api-key sk-abc123...
✓ Schlüssel gespeichert
$ secret get /deepseek/api-key
sk-abc123...
$ secret list
/deepseek/api-key
/github/token
/openvpn/cert
$ secret export
✓ 42 Secrets exportiert
Architektur

Sicher, schnell, simpel

Zweiteilig: Hintergrund-Daemon für persistente Sessions, CLI für den täglichen Zugriff. Kommunikation via Unix Socket (lokal) oder TCP (Netzwerk).

Daemon (secretd)
✅ Rust, Tokio async
✅ Unix Socket + TCP
✅ Auth-Token Auth
✅ Optional: TLS
CLI (secret)
✅ Autocomplete
✅ JSON Export
✅ .env Import
✅ Remote via --host
Vault
✅ SQLCipher
✅ AES-256-GCM
✅ macOS Keychain
✅ Keychain Timeout (3s)
SDK
✅ Python 3
✅ TCP-Transport
✅ Auth-Token
✅ Context Manager
